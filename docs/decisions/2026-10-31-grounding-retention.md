# 결정: 학교·전형 검색은 Gemini Google Search grounding, 결과 텍스트만 150일 보관 (2026-10-31)

## 결정
- 검색 방식: `school.search` operation이 Gemini `tools:[{google_search:{}}]`로 검색한다.
- 켜지는 조건 (모두 충족해야 함):
  - `GEMINI_GROUNDING_ACK=true`
  - `GEMINI_FREE_ONLY=false`
  - 기존 게이트(키, `LIVE_ACK`, 데이터 등급, 동의) 통과
- 하나라도 빠지면 `blocked` 상태가 되고 호출은 0건이다.
- 조용한 유료 전환은 하지 않는다.

## 약관 근거
출처는 Gemini API 추가 서비스 약관(https://ai.google.dev/gemini-api/terms)의 "Google 검색을 사용한 그라운딩" 조항이며, 최종 업데이트는 2026-04-28이다. 2026-10-31에 원문을 확인했다.

| 약관 조건 | 구현 |
|---|---|
| 결과는 프롬프트를 낸 최종 사용자에게만, 관련 추천 검색어와 함께 표시 | 검색 직후 응답에서만 출처 링크와 추천 검색어를 보여 준다. 추천 검색어는 `iframe sandbox`로 표시한다 |
| 결과·추천 검색어의 캐시·복사·분석·학습 금지, 다른 목적 이용 금지 | 결과를 다른 사용자와 공유하거나 캐시하지 않는다. 역량·질문 근거로 자동 투입하지 않으며, 사용자가 읽고 렌치로 직접 입력한다 |
| 결과 수정·중간 삽입 금지 | 모델 텍스트를 그대로 표시한다. 파싱·재구성하지 않는다 |
| 저장 예외: 링크를 뺀 결과 텍스트를 최대 6개월, 최종 사용자가 자기 채팅 기록을 보는 목적으로만 | 프로필 안 `search_history`에 `text`만 저장하고 기본 150일(`SEARCH_RETENTION_DAYS`) 뒤 만료한다. 출처 링크와 추천 검색어 HTML은 저장하지 않는다 |
| Google은 프롬프트·출력을 30일 저장(디버깅) | 개인정보 처리 안내 문서에 반영해야 한다 — **아직 반영하지 않음 `[TODO]`** |

## 보관과 삭제 경로
`search_history`는 다음 경우에 지워진다.
- 프로필 삭제
- 계정 삭제
- 프로필 TTL 만료(기본 30일)
- 만료 정리(`purgeExpired`)

## 한계
- 실검색 품질, 비용(월 5,000건 이후 1,000건당 $14), 한국어 모집요강 정확도는 확인하지 않았다 `[UNVERIFIED]`.
- 약관이 바뀌면 이 문서와 코드(`src/app/handlers/profiles.js` `searchSchool`)를 함께 고친다.

## 추가(2026-10-31): 지원서 분석 직후 자동 검색
- 근거 확인 화면이 열려 지원서·학교 분석이 끝나면 `school.search`를 프로필당 자동 1회 실행한다(이미 검색 기록이 있거나 서버가 꺼 두면 건너뜀). 버튼으로 다시 검색할 수 있다.
- 실검색 1회 성공 확인(건국대 수의예과, 출처 6건, 직접 조사와 일치). 결제가 연결된 새 키를 쓴다.
- 보내는 정보는 학교·학과·전형 이름과 입시 연도뿐이다. 지원서·답변은 보내지 않는다.
- 약관상 결과는 질문 근거로 자동 투입하지 않고 읽기용으로만 보여 준다. 사용자가 읽고 렌치로 역량을 직접 입력한다.
