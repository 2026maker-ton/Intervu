# 접근성·반응형·카피 점검표 (WP-D8)

기준: `docs/plan/06-uiux-spec.md` §8(접근성)·§9(반응형)·§12(UX 수용). 기준일 2026-10-29, 브랜치 `fix/p0-1-provider-gate` 기반.
"자동"은 `npm run e2e`(`tools/e2e-ui.mjs` [12]·[12b], Chromium·Mock·1440/768/390)가 실제로 검사한 항목이다. **실행하지 않은 항목은 `미실행`이며 PASS가 아니다.** 자동 검사는 axe 등 외부 도구가 아니라 페이지 내 직접 계산이므로 WCAG 전체 적합성을 뜻하지 않는다.
