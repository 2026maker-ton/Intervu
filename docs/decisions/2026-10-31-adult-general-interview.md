# 결정: 성인(만 18세 이상) 대입 전용 · 일반 면접 5단계 · 부가기능 숨김 (2026-10-31)

## 배경
- **연령 근거:** Gemini API 추가 약관은 API 사용자가 18세 이상이어야 하고, 18세 미만이 대상이거나 이용할 가능성이 높은 앱에서의 사용을 금지한다. 원문: https://ai.google.dev/gemini-api/terms
- **사용자 결정:** 이 약관 때문에 서비스 대상을 성인으로 한정하기로 했다.
- **19세 기준이 생긴 이유:** 예전 19세 기준은 Groq 약관이 아니라 "Gemini 18세 + 민법 성년 19세"를 서비스 전체에 적용한 결과였다.
  - Groq는 미성년자 대상 앱을 금지하지 않고, 법 준수 책임만 고객에게 둔다.
  - 개인정보보호법은 14세 미만에 법정대리인 동의를 요구한다.

## 결정 내용
1. **연령:** 만 18세 이상만 가입할 수 있다. 가입할 때 한 번 확인한다(`age_18_confirmed`).
   - 게이트의 `ctx.adult`는 이 기록만 본다.
   - 음성 전사 동의는 가입 고지(Groq 30일 보관·미국 처리)에 포함했다.
   - 민법 성년(19세) 미만인 18세 이용자와의 계약 취소 위험은 무료 서비스라 낮다고 판단했다. 유료화하기 전에 법률 검토가 필요하다 `[TODO]`.
2. **고입 제외:** 고입 여정을 없앴다. 서버는 고입 실입력 새 프로필을 422로 거절한다. 레거시 fixture와 테스트는 유지한다.
3. **면접 형태:** 일반 면접 5단계(도입 → 학업·전공 적합성 → 경험 검증 → 문제 해결·성찰 → 마무리)를 고정했다.
   - 특수 면접 5종(압박·블라인드·인성·기술·상황)은 진행 방식만 정의해 둔 계획 상태이고, 선택할 수 없다.
4. **질문 근거 배치:**
   - 역량·인재상은 학업 단계에 쓴다.
   - 지원서 주장은 경험 검증 단계에 쓴다.
   - 지원서의 한계 문장은 성찰 단계에 쓴다.
5. **사전 확정:** 본질문·근거·연결 문장은 승인 시점에 확정한다. 꼬리질문만 면접 중에 실시간으로 만든다.
6. **면접 진행:**
   - 답변 제한은 질문별 60초다.
   - 자동 녹음 후 발화가 끝나고 3초 정적이면 완료 여부를 판단한다.
   - 완료되면 "네 답변 잘 들었습니다."를 말하고 꼬리질문 여부를 판단한다.
   - 60초가 지나면 "네, 거기까지만 말해주시면 될 것 같습니다."를 말하고 넘어간다.
7. **숨긴 기능:** 재연습·전이 비교, 기록 화면, 관리자, 파일 업로드, 도움말, "자료 없이 일반 연습"은 UI에서 뺐다. 서버 API와 테스트는 레거시로 유지한다. 데이터 삭제 기능은 남겼다.
8. **로그인:** 이메일 + 비밀번호(PBKDF2)로 로그인한다. 로그인 토큰은 서버에 해시로만 저장한다. `DEV_TOKEN_*`은 개발·테스트용으로만 남긴다.
