## 1. 위협 모델 (데모 범위)

| 위협 | 방어 |
|---|---|
| 클라이언트 위조(플래그·ID·버전) | 서버 상태만 신뢰, 소유권 검사, 낙관적 잠금 |
| 프롬프트 인젝션(자소서·답변·URL 페이지) | 04 §4 |
| 업로드 악용(zip bomb, 거대 파일) | 크기·압축 해제 상한(`MAX_INFLATED`), 개수 상한, 5MB→정합(BUG-9) |
| 오픈 프록시 남용(TTS·진단·수집기) | TTS는 세션 문장만, 진단·지표는 관리자, 수집기는 허용 도메인 |
| 토큰 노출 | 헤더 전용, `localStorage` 한계 문서화, 로그에 헤더 비기록, 예시 토큰 경고 |
| 요금 폭주 | 사용자별 속도 제한(프로필·문서·STT·TTS·턴), 공급자 월 상한, 킬 스위치 |
| XSS | 서버 데이터는 모두 이스케이프, CSP `script-src 'self'`(현재) 유지, `innerHTML` 사용처는 `esc` 보장 |
| 데이터 잔존 | 삭제 범위 테스트, 만료 정리, 내보내기 10분 TTL |

## 2. 처리 안내·동의 (UX 명세는 06 §S2)

- **안내 문구는 실제 동작과 일치해야 한다.** 현재 사실: 서류 원문 바이너리 비저장, 텍스트는 마스킹본으로 저장, 30일 후 만료, 세션/계정 삭제 가능, 내보내기 JSON, 외부 AI는 모드에 따라 다름.
- 동의 기록(`Consent`)에는 안내 버전·연령 확인·표시한 모드 요약만 저장한다.
- **외부 AI 사용 안내는 모드별로 다르다:** Mock = "외부 전송 없음". 합성 샘플 = "합성 샘플이므로 외부 AI 사용 가능(표시)". 실데이터 + 승인된 공급자 = "마스킹한 텍스트가 <공급자>로 전송됩니다" + 전송 항목 목록. 약관 확인 전 공급자는 실데이터 경로 자체가 없다.
- 개인정보 마스킹은 **완전 익명화가 아니다.** 입력란 근처와 안내에 항상 고지한다.

## 3. 로그·감사

- 기록: `request_id`, 경로, 상태, 지연, 공급자 호출 메타(`ProviderCall`). **기록 금지:** 서류·답변 본문, 키, 토큰, 오디오.
- 관리자 행위(트렌드 초안·공개·롤백·중단)는 `approved_by`(관리자 식별 가능한 값 — 단일 토큰이면 "admin")와 시각을 남긴다.
